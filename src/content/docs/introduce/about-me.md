# Raincoat

![profile.jpeg](/images/profile.jpeg)

프론트엔드 개발자 우상욱입니다. 어릴 때 컴퓨터를 분해하고 다시 조립하는 걸 좋아했습니다. 특성화고에서 웹 개발을 처음 배웠고, 코드 한 줄을 고쳐도 결과를 바로 확인할 수 있다는 점이 재미있어 프론트엔드를 선택했습니다.

React와 Vue로 웹 서비스를 개발해 왔습니다. 기능을 구현할 때는 사용자가 어떤 순서로 이용하는지 먼저 생각하고, 구현한 뒤에는 그 순서대로 직접 확인합니다.

이 블로그에는 회사와 개인 프로젝트에서 개발하면서 배운 것을 기록합니다. React와 TypeScript 사용 예제, Git과 배포 과정에서 겪은 문제를 다룹니다. 실무에서 만난 오류는 나중에 다시 참고할 수 있도록 확인한 원인과 해결 방법을 함께 적습니다.
