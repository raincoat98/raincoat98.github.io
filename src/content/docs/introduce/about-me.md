# Raincoat

![profile.jpeg](/images/profile.jpeg)

프론트엔드 개발자 우상욱입니다.

## 개발을 시작한 계기

어릴 적에는 컴퓨터 본체를 분해하고 다시 조립하는 일을 좋아했습니다. 특성화고에서 웹 개발을 처음 배웠고, 코드를 고치면 화면이 바로 바뀌는 점이 재미있어 프론트엔드로 방향을 잡았습니다. 지금은 React와 Vue로 개발합니다.

## 일할 때 중요하게 보는 것

버튼 하나를 만들 때도 사용자가 어떻게 쓸지부터 생각합니다. 화면이 의도대로 동작하는지 직접 눌러 보고, 문제가 생기면 원인을 확인한 뒤 고칩니다. 현장에서 쓰는 시스템을 만들면서 이 과정이 더 중요해졌습니다.

## 이 블로그에 쓰는 것

회사와 개인 프로젝트에서 부딪힌 문제와 해결 과정을 정리합니다. 같은 문제를 다시 만났을 때 참고할 수 있도록, 확인한 내용과 실행한 명령을 함께 남깁니다.
