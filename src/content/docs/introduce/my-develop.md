# 왜 개발자가 되었나요?

어릴 적에는 컴퓨터 본체를 분해하고 다시 조립하는 일이 재미있었습니다. 고장 난 컴퓨터를 고쳐서 다시 켰을 때의 기분이 아직도 기억납니다.

특성화고에서 웹 개발을 처음 배웠습니다. 코드를 고치면 화면이 바로 바뀌는 점이 신기했고, 직접 만든 것이 눈앞에 나타나는 일이 가장 재미있었습니다.

개발을 배우면서 자연스럽게 프론트엔드로 방향을 잡았습니다. 버튼 하나를 만들 때도 사용자가 어떻게 쓸지 고민하게 되는데, 그 결과가 화면에 바로 보이는 점이 저와 잘 맞았습니다. 서버처럼 눈에 보이지 않는 곳의 코드도 중요하지만, 사용자와 가까운 자리에서 화면을 만드는 일이 더 좋았습니다.

지금도 만든 화면을 누군가 실제로 쓸 때 보람을 느낍니다. 프론트엔드는 배울 것이 계속 늘어나지만, 그만큼 성장이 눈에 보이는 분야입니다. 앞으로도 이 과정을 이어 가려 합니다.
